# Yumble

**Watch it all tumble together.** An interactive food-ordering experience where you build a meal ingredient-by-ingredient and watch it come together visually, instead of picking options off a list.

See [DESIGN.md](./DESIGN.md) for the full problem statement, target users, scope, and tech stack.

## Status

🚧 In progress — currently in the wireframing phase. Figma prototype and live demo links will be added here as they're ready.

## Tech Stack

Next.js · React · TypeScript · Tailwind CSS · Framer Motion

## Getting Started

```bash
npm install
npm run dev
```
